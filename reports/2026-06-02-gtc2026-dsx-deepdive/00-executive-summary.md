## 🏆 Boss 的三条投资逻辑链(投委会打印用)

### 链 1:AIDC 主电源瓶颈
**逻辑:** AI 算力 1GW 集群 = 主电源瓶颈。GE Vernova 100 GW 气轮机 backlog 锁至 2029+;on-site 发电(燃气轮机+储能)27% 新数据中心 2030 标配。
**标的:** **Long GE Vernova (GEV)9.0 分** / Long Mitsubishi Power 7.0 分

### 链 2:AIDC 工业品(液冷+UPS+PDU+CDU)
**逻辑:** NVIDIA DSX 把 infra builders 推上"系统集成商"地位,Vertiv / Eaton / Schneider 整厂交付 ASP 抬升 3-5x;800 VDC + SST 拐点 2026-2028。
**标的:** **Long Vertiv (VRT)9.5** / **Long Eaton (ETN)8.5** / Long Delta 台达 2308.TW 8.0 / Long Schneider SU.PA 8.0
**黑天鹅:** DG Matrix($60M A 轮,已入 NVIDIA MGX)如果 2027 H2 量产,Delta/Eaton/ABB 1-2 年领先优势可能被追平

### 链 3:Power-first AI Cloud(配对交易 + 区域新势力)
**逻辑:** 电力稀缺 → Power-first AI cloud 重估。CoreWeave + IREN 是 NVIDIA 验证的双标杆;区域玩家 Nscale / Firmus / YTL 是 Pre-IPO 高弹性。
**标的:**
- **配对:** Long IREN / Short CRWV(押 2027 缺电叙事)
- **Pre-IPO:** Nscale $14.6B / Firmus $5.5B / YTL(上市平台 YTLP)
- **公开市场:** Sharon AI (SHAZ)
- **观察池:** Indosat / Visionbay / GMI Cloud / ResetData

## 🌍 GTC 2026 三大战略信号(给合伙人讲用)

1. **"AI Cloud"独立成行** — Jensen 把 AI Cloud 从传统 Cloud 切出来 → 投资机会在 regional AI cloud(澳/印尼/欧/印度),不在 AWS/Azure 附庸
2. **"Energy & Cooling"层是真正瓶颈** — 13 家公司里 Vertiv / GEV / Eaton 三家是"吃下 DSX reference design"的真赢家
3. **"Power-first"是新护城河** — IREN 5 GW 自持 vs CoreWeave 1 GW 在线 = 估值应该重估的信号
